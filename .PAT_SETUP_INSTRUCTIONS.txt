To make the update-data.sh work NON-INTERACTIVELY from your R script (no more username/password prompts):

1. Go to https://github.com/settings/tokens
2. Generate a new "Personal access token (classic)"
   - Note: "p6v2-autoupdate"
   - Expiration: 90 days or whatever
   - Scopes: ONLY check "repo" (full control of private repositories)
3. Copy the token (starts with ghp_...)
4. Run these commands:
   echo 'ghp_YOUR_TOKEN_HERE' > ~/.p6v2_github_pat
   chmod 600 ~/.p6v2_github_pat
5. Test:
   cd ~/p6v2-public-stats
   ./update-data.sh
   # It should now push without prompt (using the token temporarily, then restores the safe remote URL)

The token is ONLY read by the helper for the push command. It is never committed or printed.

If you prefer SSH (more secure, no token file):
- ssh-keygen -t ed25519 -C "your@email"
- cat ~/.ssh/id_ed25519.pub   # add this key to GitHub account settings > SSH keys
- Then in the clone:
  git remote set-url origin git@github.com:jvhoang/p6v2-public-stats.git
- And make sure ssh-agent is running (usually is on Mac).

After setup, your R script's system() call will update the repo silently (check the log file).
